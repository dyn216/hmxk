# 🚀 后端一键部署脚本使用指南

## 📋 概述

提供了两个功能完整的一键部署脚本，支持后端服务的完整生命周期管理。

### 脚本文件
- **Windows**: `deploy.bat`
- **Linux/Mac**: `deploy.sh`

---

### 1. 完整部署（首次安装）
- ✅ 检查Python环境
- ✅ 创建虚拟环境
- ✅ 安装所有依赖（使用清华源加速）
- ✅ 初始化数据库
- ✅ 创建日志目录

### 2. 服务管理
- ✅ 启动服务（后台运行）
- ✅ 停止服务
- ✅ 重启服务
- ✅ 查看服务状态

### 3. 维护功能
- ✅ 更新依赖包
- ✅ 重置数据库（清空所有数据）
- ✅ 查看日志
- ✅ 完全卸载环境

## 🚀 快速开始

### Windows系统

```bash
# 方法1：双击运行
deploy.bat

# 方法2：命令行运行
cd e:\tzb\backend
deploy.bat
```

### Linux/Mac系统

```bash
# 添加执行权限（首次运行）
chmod +x deploy.sh

# 运行脚本
./deploy.sh
```

## 📖 使用说明

### 首次部署流程

1. **运行脚本**
   ```bash
   # Windows
   deploy.bat
   
   # Linux/Mac
   ./deploy.sh
   ```

2. **选择选项1 - 完整部署**
   - 等待自动完成所有安装步骤
   - 大约需要2-5分钟（取决于网络速度）

3. **选择选项2 - 启动服务**
   - 服务将在后台运行
   - 访问 http://localhost:8000 查看

### 日常使用

#### 启动服务
```
选择选项2
```
- 自动检查端口占用
- 后台启动服务
- 显示访问地址

#### 停止服务
```
选择选项3
```
- 自动查找进程
- 安全停止服务
- 释放端口

#### 重启服务
```
选择选项4
```
- 先停止后启动
- 自动检查状态

```

```
显示信息：
- 服务运行状态

- 环境完整性检查

#### 查看日志

- 便于排查问题

## 🐛 常见问题

### 问题1：端口被占用
```
[警告] 端口8000已被占用
```
**解决方法**：
1. 选择选项3停止服务
2. 或手动结束占用端口的进程

**Windows查看端口占用**：
```bash
netstat -ano | findstr :8000
taskkill /PID [进程ID] /F
```

**Linux查看端口占用**：
```bash
lsof -i:8000
kill [进程ID]
```

### 问题2：虚拟环境创建失败
```
[错误] 创建虚拟环境失败
```
**解决方法**：
1. 检查Python版本（需要3.8+）
2. 检查磁盘空间
3. 检查Python是否正确安装

### 问题3：依赖安装失败
```
[错误] 依赖安装失败
```
**解决方法**：
1. 检查网络连接
2. 尝试手动安装：
   ```bash
   source venv/bin/activate  # Linux/Mac
   # 或
   venv\Scripts\activate.bat  # Windows
   
   pip install -r requirements.txt
   ```

### 问题4：数据库初始化失败
```
[错误] 数据库初始化失败
```
**解决方法**：
1. 检查是否有写入权限
2. 删除已存在的数据库文件
3. 重新运行完整部署

### 问题5：服务启动失败
```
[错误] 服务启动失败
```
**解决方法**：
1. 选择选项8查看日志
2. 检查配置文件是否正确
3. 确认所有依赖已安装

## 💡 使用技巧

### 技巧1：快速重启开发
开发过程中修改代码后：
```
选择选项4 - 重启服务
```
会自动停止并重新启动，加载新代码。

### 技巧2：查看实时日志
想要查看详细日志：
```bash
# Windows
powershell -command "Get-Content logs\server.log -Wait -Tail 50"

# Linux/Mac
tail -f logs/server.log
```

### 技巧3：生产环境部署
生产环境建议：
1. 使用非root用户运行
2. 配置systemd服务（Linux）
3. 使用nginx反向代理
4. 配置HTTPS证书
5. 修改默认端口
6. 使用环境变量存储敏感信息

### 技巧4：定期备份数据库
```bash
# 备份数据库
cp chronic_disease.db chronic_disease_backup_$(date +%Y%m%d).db

# 恢复数据库
cp chronic_disease_backup_20241217.db chronic_disease.db
```
